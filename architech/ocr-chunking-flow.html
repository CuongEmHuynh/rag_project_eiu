Flowchart · OCR pipeline

OCR JSON to Retrieval Chunks Flow

Phase 01

Input cleanup

Nạp OCR JSON, tách các block văn bản, chuẩn hóa tọa độ/nội dung và loại bỏ nhiễu rõ ràng trước khi phân tích cấu trúc.

Phase 02

Reading structure

Sắp xếp block theo thứ tự đọc, nhận diện vùng tài liệu như tiêu đề, điều khoản, đoạn văn, bảng và nối lại bảng bị tách qua nhiều trang.

Phase 03

Tree and atomic units

Dựng cây tài liệu theo quan hệ cha-con, sau đó tạo các atomic units làm đơn vị nhỏ nhất còn giữ nguyên ngữ nghĩa.

Phase 04

Chunk construction

Đóng gói theo giới hạn token, tạo parent chunks và child chunks, sinh retrieval_text, kiểm tra hợp lệ rồi trả về chunks cho truy xuất.
